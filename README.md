# Portfolio personal de Erick Terranova

Portafolio personal desarrollado con HTML, CSS y JavaScript para presentar información profesional, proyectos destacados, habilidades y métodos de contacto.

## Descripción

Este proyecto consiste en una landing page personal orientada a un perfil de estudiante de Ingeniería en Software con interés en análisis de datos, desarrollo web y soluciones tecnológicas. El sitio incluye:

- presentación personal
- sección de habilidades
- proyectos destacados
- diseño y visualización moderna
- formulario de contacto
- diseño responsive para distintos dispositivos

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages para despliegue
- FormSubmit para envío de formularios

## Instrucciones de visualización

### Opción 1: abrir directamente en el navegador
1. Ubícate en la carpeta del proyecto.
2. Abre el archivo `portfolio/index.html` en tu navegador.

### Opción 2: visualizar desde un servidor local
Puedes usar una extensión de VS Code como Live Server o ejecutar un servidor local simple.

Ejemplo con Python:

```bash
cd "C:\Users\Erick Terranova\Desktop\My CV"
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000/portfolio/
```
